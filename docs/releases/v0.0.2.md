# v0.0.2

本版本补齐 AstrBot 原生行为注册，并改善首次配置与多模型人设体验。

## 主要变化

- `/故事`、`/存档`、`/读档` 和 `/圆桌会议` 现在会显示在 AstrBot 指令管理中。
- 新增 `interactive_fiction` LLM 函数工具；自然语言请求仍须经过全局判断模型。
- 圆桌模型条目默认启用，圆桌与全局判断人设输入框提供可编辑预设。
- 空白旧配置会按提案/评审与常规/非安全类型动态补全人设；非安全预设强化暴力、血腥和性题材的直接表现能力。
- 配置面板中的故事、圆桌模型、绘图工作流和自定义节点统一显示名称副标题。
- 并发行动现在明确提示等待；自然语言指定越界存档槽时会返回固定范围错误。

## 验证

- 22 项核心回归测试通过。
- 7 项 AstrBot 实际注册与入口集成测试通过。
- 版本一致性、JSON schema、Python 语法和发布包大小校验通过。

## 兼容性

- AstrBot `>=4.10.4,<5`
- OneBot v11 / `aiocqhttp`
- Python `>=3.10`
