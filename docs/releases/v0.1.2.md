# v0.1.2

本版本把高频故事内容从全量圆桌改为“全局故事生成 LLM 直接生成、配置时机按需进入圆桌”，重点降低普通行动等待时间，同时保留关键内容的多模型讨论能力。

## 主要变更

- 配置面板新增全局故事生成 LLM、预设人设和六类圆桌触发时机，默认启用非安全内容与底稿。
- 玩家行动并发请求全局判断和全局故事生成模型；判断结果只负责路由，剧情结果仍由故事生成链路决定。
- 轮流讨论从全局故事输出继续，单独提案在评审阶段融合该输出；模型底稿不显示在圆桌合并转发中。
- 未配置或调用全局故事模型失败时回退圆桌，兼容既有 v0.1.1 配置。
- 圆桌条目使用 AstrBot 官方单字段 `display_item`，组合值为“名称——身份——生成的内容类型”。
- `/查看故事` 取代旧回复重发用法；`/故事 继续` 恢复为自由行动。
- 开局人物图最终提示词包含玩家已看到的当前环境，减少背景与开场不一致。

## 验证

- 49 项核心单元测试通过。
- 22 项真实 AstrBot 注册与消息路由集成测试通过。
- Python 编译、配置 JSON、发布元数据和运行包大小校验通过。
