# v0.1.1

本版本对 `v0.1.0` 的完整功能链路进行了回归审查，重点修复圆桌记录、多人回档重入和后台绘图边界。

## 修复

- 保存开局及加入角色时的最近圆桌讨论，`/圆桌会议` 可查看最近一次生成记录。
- 回档移除角色后，自然语言行动会提示重新加入，并支持自然语言重入原房间。
- 提案全部失败时停止生成，不再由评审绕过提案直接产出。
- 已有行动占用房间时，指令行动不再重复调用全局判断模型。
- 待选故事可以通过 `/故事 [编号/名称/全随机]` 完成选择。
- 防止回档后仍发送旧时间线生成的图片，并在正文发送失败时取消对应后台任务。

## 健壮性

- 未启用绘图条目时跳过图像时机判断。
- 严格校验故事选项字符串、ComfyUI 必需节点映射和空提示词。
- 单张生成图片限制为 32 MB，避免异常上游响应耗尽内存。
- 状态文件局部损坏时跳过无效房间或存档，不阻塞插件初始化。
- 回档不再恢复已经离开房间玩家的死亡、立绘和交谈状态。
- 使用 AstrBot 自动插件发现机制，移除已弃用的 `@register` 装饰器。

## 验证

- Python 核心与真实 AstrBot 集成回归测试全部通过。
- Python 编译、配置 JSON、依赖完整性和发布元数据校验全部通过。
