# v0.2.0

本版本将常规与非安全故事生成拆分为独立全局模型，并引入持久化的角色生命值、淫乱值、战损 CG 与首次相遇随机事件。

## 主要变更

- 新增“全局非安全内容 LLM”及独立人设。非安全任务默认使用该模型，只有命中已勾选的“非安全内容”触发项时才进入非安全圆桌。
- 全局判断 LLM 在故事正文生成后根据客观结果裁定受伤角色与扣血量，不参与剧情结果创作。
- 玩家和 NPC 均缓存 0 至 100 的生命值及淫乱值，旧房间和旧存档自动补齐默认值并钳制异常数据。
- 生命值跨过 80、60、40、20、0 档位时，同角色每轮最多生成一张 CG；40 及以下使用严重战损提示，归零时按杀害和尸体处理。
- 固定杀害选项继续保证 100% 成功，并确定性将交谈目标生命值归零。
- 淫乱值按百分比影响角色首次相遇时的自主事件概率。事件每轮最多一次，由非安全故事生成链路生成，并作为独立消息及缓存分段发送。
- 插件只负责常规与非安全模型路由，不进行额外年龄或 18+ 内容过滤。
- 非安全人物图片只选择自由 OpenAI 兼容条目或本地 ComfyUI；后续改图始终使用角色首次 CG 作为基底。
