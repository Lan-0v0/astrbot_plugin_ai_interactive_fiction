# v0.0.4

本版本完善开局信息展示、生成字数控制和人物绘图风格配置。

## 主要变化

- 房主开局和多人加入均按“个人信息、视野所及环境、人物立绘”的顺序分段发送。
- 使用全局判断 LLM 提取玩家当前可感知的环境，不展示隐藏世界观、剧情、伏笔或视野外 NPC。
- 在“流式输出”下方新增可收起或展开的字数限制配置。
- 分别控制常规正文、非安全正文、个人信息、环境和心理描述的提示词字数上限。
- 保持提示词软限制，不对模型偶尔超出的输出进行硬截断。
- OpenAI 兼容与 ComfyUI 绘图条目均新增“画风”，并位于提示词生成模型下方。
- 指定画风既会提供给提示词 LLM 以避免风格冲突，也会确定性添加到最终生图或改图提示词开头。
- 兼容迁移旧版未修改的 `30/200` 字默认内容限制，避免与新配置重复或冲突。

## 验证

- 29 项核心回归测试通过。
- 9 项 AstrBot 实际注册与入口集成测试通过。
- 18 个 Python 文件语法检查通过。
- 配置 schema、条件显示、字段顺序、旧配置迁移和发布元数据均已校验。

## 兼容性

- AstrBot `>=4.10.4,<5`
- OneBot v11 / `aiocqhttp`
- Python `>=3.10`
