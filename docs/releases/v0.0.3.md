# v0.0.3

本版本修复配置面板条目辨识问题，并将圆桌模型人设拆分为真正独立的常规与非安全配置。

## 主要变化

- 修正五类模板的 `display_item` 类型，折叠后会显示“名称: 当前名称”副标题。
- 人物绘图说明改为首次文生图、后续缓存图改图，并明确按优先级失败切换。
- “生成的内容类型”移动到“选择模型提供商”下方。
- 常规与非安全内容分别拥有独立、条件显示且可编辑的人设预设。
- 兼容 `v0.0.2` 的旧 `persona` 配置，已自定义内容不会因升级丢失。
- `/故事` 使用更直观的分区帮助菜单。

## 验证

- 24 项核心回归测试通过。
- 8 项 AstrBot 实际注册与入口集成测试通过。
- 配置 schema、条件显示、字段顺序、旧配置迁移、帮助菜单、JSON 和 Python 语法均已校验。

## 兼容性

- AstrBot `>=4.10.4,<5`
- OneBot v11 / `aiocqhttp`
- Python `>=3.10`
