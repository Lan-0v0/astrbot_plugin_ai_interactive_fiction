# v0.1.0

本版本重构自然语言作用域、行动指令、选项展示与故事图像生成流程。

## 主要变化

- 未开局消息完全跳过插件全局判断 LLM，避免拖慢普通聊天或消耗额外 Token。
- 新增 `/故事 继续`，重发最近一次行动的结果、选项和已经完成生成的图片。
- 新增 `/故事 1/2/3` 和 `/故事 [行动]`，明确指令行动仍经过合理性与内容类型判断。
- 每轮由圆桌生成三项剧情选择；插件根据交谈状态追加固定的自由行动、杀害和侵犯选项。
- 开局先发送可见环境，再发送人物介绍和四项选择；首次人物图在后台生成。
- 图像生成时机支持人物首次登场、人物首次对话、杀害、侵犯、场景变换和人物战损。
- 故事正文先发送并释放行动锁，后台再完成图像时机判断、生成、发送和回复缓存更新。
- 圆桌模型折叠副标题组合显示名称、身份和内容类型。
- 结构化评审输出支持平衡 JSON 提取、流式网关兼容、自动格式修复和有效评审回退。

## 验证

- 52 项核心及 AstrBot 集成回归测试通过。
- 覆盖未开局路由、函数工具门控、指令解析、固定选项、回复与图片缓存、后台任务、场景提示词和图像时机过滤。
- Python 语法、配置 Schema、版本一致性和发布文件校验通过。

## 兼容性

- AstrBot `>=4.10.4,<5`
- OneBot v11 / `aiocqhttp`
- Python `>=3.10`
