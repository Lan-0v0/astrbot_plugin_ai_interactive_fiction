# v0.1.3

本版本修复群聊中 `@机器人 3` 等简短选项未被识别为故事行动的问题，并校正玩家行动的拒绝边界。

## 主要变更

- 有效候选编号及 `选3`、`第三项`等明确表达先由插件确定性解析，再进入既有行动锁、合理性判断和故事生成流程。
- OneBot 首个 `@机器人` 从纯文本中移除后，剩余编号仍能被正确识别；同时兼容从消息链提取纯文本的适配形式。
- 消息监听和 `interactive_fiction` 函数工具使用同一套选项解析规则。
- 只有主角依据当前状态无法实施的行动，或玩家直接宣告尚未裁定的成功结果才会被拒绝。
- 暴力、血腥、性或其他非安全题材只影响内容模型路由，不作为拒绝依据，具体结果仍由故事模型裁定。

## 验证

- 50 项核心单元测试通过。
- 27 项真实 AstrBot 注册与消息路由集成测试通过。
- Python 编译、发布元数据、Git 标签一致性和运行包大小校验通过。
